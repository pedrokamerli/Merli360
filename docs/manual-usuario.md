# Manual do usuario

## Gestao da Grafica

1. Acesse `Gestao da Grafica` no menu.
2. Use a aba `Painel` para indicadores, rankings e relatorios CSV.
3. Use a aba `Base` para importar planilha, cadastrar produtos, materiais, processos, parametros, funil e papeis.
4. Use a aba `Comercial` para cadastrar cliente/oportunidade, montar orcamento e acompanhar o funil.
5. Cadastre ou localize um cliente, inclusive quando o pedido vier de outro canal de venda.
6. Crie uma oportunidade com proximo passo e data de retorno.
7. Use `Contato` para registrar uma conversa, `Reagendar` para criar novo retorno ou `Perder` para encerrar com motivo.
8. Gere um orcamento a partir da oportunidade.
9. Movimente oportunidades pelo funil visual sem perder o proximo passo.
10. Vincule um produto cadastrado ao orcamento, se aplicavel.
11. Confira custo, margem, desconto e alertas.
12. Envie, duplique, recuse ou cancele o orcamento quando necessario.
13. Se houver alerta de margem/desconto, use `Aprovar excecao` antes de gerar o pedido.
14. Use `Gerar pedido` quando o cliente confirmar.
15. O sistema cria pedido e ordem de producao automaticamente.
16. Use a aba `Producao` para checklist, etapas, consumo, retrabalho e anexos de evidencia.
17. Use a aba `Entregas` para agendar entrega, registrar responsavel, anexar comprovante e marcar aceite.
18. Use a aba `Recebimentos` para registrar pagamentos parciais ou totais por parcela.
19. Use a aba `Pos-venda` para fechar contato com satisfacao de 1 a 5.
20. Se houver reclamacao, baixa satisfacao ou chance de nova venda, crie uma nova oportunidade/tarefa pelo proprio contato de pos-venda.

Quando um indicador aparecer como `Dados insuficientes`, significa que ainda nao ha registros confiaveis para o calculo.
Abra os detalhes do indicador para conferir formula, fonte, periodo e criterio usado no painel.
Se um valor financeiro aparecer como `Restrito`, seu perfil nao tem autorizacao para ver esse indicador.
Se um relatorio nao baixar por permissao, solicite ajuste do seu perfil operacional da grafica.
Quando um material ou processo aparecer como `Validar`, confira o custo real antes de usar como referencia comercial definitiva.
Uma ordem so deve ser liberada para producao quando arte, medidas, material, prazo e arquivos estiverem conferidos.
Arquivos anexados nao ficam em pasta publica; o acesso passa pela autenticacao do sistema.
